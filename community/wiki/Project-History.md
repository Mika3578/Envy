# Project history

Envy’s story spans Shareaza-lineage code, the PeerProject era, the GetEnvy/Envy releases, and today’s maintained fork.

**Do not** describe Envy as “Shareaza renamed.” See [Shareaza-and-PeerProject-Lineage](Shareaza-and-PeerProject-Lineage).

## Eras

1. **Shareaza** — reference multi-network client; G1/G2 heritage in Envy code.
2. **PeerProject** — continued Shareaza-lineage development under its own branding.
3. **Envy (GetEnvy)** — rebrand and tagged releases (2016–2020 on GitHub).
4. **Mika3578/Envy** — active modernization fork with preview release track.

## Maintainer note (2019)

A post on the Shareaza forum announced Envy 2.0, describing roughly two years of development from a PeerProject mirror and presenting Envy as the active continuation of that work. Treat as **maintainer narrative**, not a legal transfer of the Shareaza project.

## Current fork

See the main repository README and status matrix for **today’s** scope. Historical website claims are not automatically current.
