# Shareaza and PeerProject lineage

## Shareaza (context)

Shareaza is an open-source Windows multi-network client. Envy documentation references Shareaza for **Gnutella/G2 behaviour and code heritage**, not as the governing project of the modern fork.

## PeerProject

PeerProject was presented as a Shareaza-lineage fork with its own releases and community (SourceForge, historical sites). Upstream Envy credits PeerProject as the immediate predecessor **name**.

## Envy rebrand

Upstream ReadMe text states Envy was previously developed as PeerProject and originally derived from Shareaza. That describes **continuation and rebrand**, not a single rename event.
