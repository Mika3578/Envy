# Contributing

1. Read [CONTRIBUTING](https://github.com/Mika3578/Envy/blob/develop/.github/CONTRIBUTING.md) and [AGENTS.md](https://github.com/Mika3578/Envy/blob/develop/AGENTS.md).
2. Branch from `develop` using `type/short-kebab-summary` names.
3. Open a pull request to `develop` (squash merge policy).

## Where to discuss first

- **Questions:** [Discussions](https://github.com/Mika3578/Envy/discussions) (Q&A category)
- **Bugs:** Issues with reproduction steps
- **Security:** [SECURITY.md](https://github.com/Mika3578/Envy/security/policy) — private report

## Wiki and website changes

Edit `community/wiki/` or `site/` in the main repository so reviewers see diffs. Publish Wiki to `.wiki.git` after merge (see `community/wiki/README.md`).
