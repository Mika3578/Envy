**Search filter mask mapping (#432)** - `Settings.Search.FilterMask` is now decoded through one canonical mapping (`Envy/SearchFilterMask.h`): bit 4 = hide local files, bit 5 = hide rejected results. `CFilterOptions` previously decoded the two bits in the opposite order from the only writer (`CMatchList::Filter()`), so a mask written by one path read back with Local and Reject swapped on the other. Readers now use named `SEARCH_FILTER_*` constants instead of raw bit positions; persisted settings keep their meaning and no upgrade-time swap occurs. EnvyTests round-trip all 2,048 combinations of the 11 filter bits and pin the persisted bit positions.
