**Gzip resource staging (#478)** - The embedded HTML resource build step (`About.htm.gz`/`Browser.htm.gz`) now compresses into a temporary file and replaces the tracked resource only after the bundled compressor exits successfully and the staged file passes `gzip -t` integrity checking. A failed compressor launch or truncated write can no longer leave an invalid embedded resource; the previous output is preserved byte-for-byte and the build fails closed. Compressor, flags and byte-level output format are unchanged.
