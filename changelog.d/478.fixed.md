**Gzip resource staging (#478)** - The embedded HTML resource build step (`About.htm.gz`/`Browser.htm.gz`) now compresses into a per-configuration staging file and replaces the tracked resource only after the bundled compressor exits successfully and the staged file passes `gzip -t` integrity checking, so a failed compressor launch or truncated write preserves the previous output byte-for-byte and fails the build. Compressor, flags and byte-level output format are unchanged.
