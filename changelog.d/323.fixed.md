**Direct Connect hublist URI parsing (#323)** - Every hublist row is now classified by scheme before host extraction (`Envy/DcHubUri.h`): `dchub://` keeps working, `nmdc://` is accepted as a plaintext NMDC alias, and `nmdcs://` is rejected explicitly because no TLS transport exists - without DNS attempts or plaintext fallback, which stops the runtime from repeatedly resolving the literal hostname `nmdcs`. Host cache entries saved by older importers with a scheme URI are normalized to the bare authority or removed on startup. ADC/ADCS rows stay skipped pending separate ADC/ADCS support. Host, explicit port, IPv4 literals and DNS names are validated without truncation; bracketed IPv6 authorities (the DC connect path is IPv4-only), missing hosts, bad ports (empty/zero/leading zero/over 65535), extra colons, path suffixes, embedded whitespace and overlong forms fail closed on untrusted hublist input.
