**Gnutella THEX source preservation (#453)** - Envy no longer sends a speculative legacy `/gnutella/thex/v1` request before file bytes; THEX tree downloads happen only against a peer-advertised `X-Thex-URI`/`X-TigerTree-Path` endpoint. A THEX endpoint that refuses the request (400/403/404/410/501/503) is treated as a metadata-only failure: the source is kept and the ordinary file transfer continues — on the same connection when the small error body can be drained, otherwise after reconnecting — so a server without a THEX handler can no longer cost the download its only source. Tree verification is unchanged where an endpoint is advertised.
