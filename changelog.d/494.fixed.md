**Download verification deferral (#494)** - Verification events from the Library are no longer dropped when the Transfers section is briefly busy: `CDownloads::OnVerify` queues the event by library path (no raw file pointer retained) and the next transfers tick replays it under Library-then-Transfers locks, matching the forward path's order. Pending events are de-duplicated per path with the freshest result winning, bounded at 64 entries, and deferrals are counted with a rate-limited diagnostic; deleted files or removed downloads simply drop the moot event. Uncontended verification behavior is unchanged.
