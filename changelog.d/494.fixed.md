**Download verification deferral (#494)** - Verification events from the Library are no longer dropped when the Transfers section is briefly busy: `CDownloads::OnVerify` queues the event by library path (no raw file pointer retained) and the next transfers tick replays it under Library-then-Transfers locks, matching the forward path's order. A result applied while the lock is free cancels any older pending event for the same path, so replay cannot overwrite fresher state; pending events are de-duplicated per path, bounded at 64 entries with counted eviction, and every deferral is counted with a rate-limited diagnostic. Deleted files drop the moot event. Uncontended verification behavior is unchanged.
