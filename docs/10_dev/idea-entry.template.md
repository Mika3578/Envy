# Inbox / ideas entry template

Copy into `.local/inbox/<category>.md` (gitignored) or, after review, into
[`ideas.md`](ideas.md). Titles must be readable without an internal id.

```markdown
## Adaptive bandwidth — Adjust transfer rates to current network conditions

Added: 2026-10-06
Source: observation / ChatGPT / Codex / Cursor / developer
Area: Network / Transfers
Suggested priority: P3
Confidence: Medium

### Observation
Standalone description of the problem or idea. A reader who never saw the
chat should still understand it.

### Expected benefit
Concrete benefit if the work is done.

### Possible scope
Likely files, networks, or subsystems.

### Before promoting
What to verify or measure before this becomes official work.

### Related work
Existing Issues/PRs/docs with **number and title**, for example
`#111 — Reproducible runtime benchmarks`, not `#111` alone.

### Status
Pending review
```

Allowed durable statuses after review: Candidate, Needs research, Accepted,
Tracked, Deferred, Rejected, Implemented, Superseded.

Stable ids (optional) must still accompany a title and description.
