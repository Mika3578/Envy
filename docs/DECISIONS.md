| D-010 | 2026-09-17 | Targeted IGD discovery via `upnpDiscoverDevices(..., searchalltypes=1)` — one MiniUPnPc discovery receive phase for requested ST values, not 4× sequential legacy searches. `UPnPTimeout` is the per-receive delay in MiniUPnPc 2.0 (not a strict wall-clock SSDP deadline); absolute SSDP/HTTP bounding is #142 / P3. Call `UPNP_GetValidIGD` once on filtered candidates; never treat result 3 as WAN target. | On LANs with multiple UPnP responders, legacy sequential discovery could fetch unrelated device descriptions and significantly delay NAT setup when no usable IGD advertisement was available. | Active |
| D-011 | 2026-09-17 | Network listen sockets must not wait for NAT traversal methods to finish. Order: select interface → bind/listen → network up → async NAT → update external ports.
